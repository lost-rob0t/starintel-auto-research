#+title: STAR-PRO-RESEARCH-004 hCaptcha Provider Gap Audit
#+description: Audit of well-known CAPTCHA providers whose current public documentation does not support a production hCaptcha token adapter.
#+status: REVIEW
#+filetags: :starintel:research:starintel-pro-actors:captcha:hcaptcha:provider-drift:rejected:

* Scope

This note prevents StarIntel from implementing stale hCaptcha integrations copied from old examples, client libraries, or third-party tutorials. It covers CapSolver, Anti-Captcha, and CapMonster Cloud as of 2026-08-05.

* Decision Summary

| Provider | Current public hCaptcha token task | Decision |
|----------+------------------------------------+----------|
| CapSolver | Not listed in current supported-task or pricing pages | Do not implement |
| Anti-Captcha | Not listed in current task catalog | Do not implement |
| CapMonster Cloud | Not listed in current captcha catalog; prior reports show unsupported-task errors | Do not implement |

The absence of a current public task does not prove that a private or transitional service does not exist. It does prove that StarIntel lacks an authoritative contract suitable for production implementation.

* CapSolver

The current CapSolver supported-task page lists image recognition, reCAPTCHA, GeeTest, MTCaptcha, DataDome, Amazon Web Services Web Application Firewall[fn:aws-waf], Cloudflare Turnstile, and Cloudflare Challenge. hCaptcha is absent. The current pricing page is also missing an hCaptcha line.

Older third-party integrations that claim CapSolver hCaptcha support are therefore not authoritative. No adapter is designed until CapSolver publishes a current hCaptcha task page and a successful live contract test confirms it.

* Anti-Captcha

The current Anti-Captcha documentation index lists reCAPTCHA, Arkose Labs FunCaptcha, GeeTest, Turnstile, custom AntiGate tasks, Prosopo, Friendly Captcha, Amazon WAF, Altcha, and image tasks. hCaptcha is absent.

Old package names, marketing text, or archived pages must not be treated as a supported contract. No adapter is designed.

* CapMonster Cloud

The current CapMonster Cloud overview and captcha catalog advertise reCAPTCHA, Turnstile, GeeTest, Friendly Captcha, MTCaptcha, Arkose Labs FunCaptcha, and other task families, but not hCaptcha. A public support discussion from 2025 records =ERROR_TASK_NOT_SUPPORTED= for hCaptcha and points back to the provider catalog.

Because the official current catalog is the authority, no adapter is designed.

* Reconsideration Gate

A rejected provider may be reconsidered only when all of these exist:

1. A current official provider page naming an hCaptcha token task.
2. A documented create request and result request.
3. A documented token field and enterprise =rqdata= behavior.
4. A documented authentication method and error table.
5. A live test against an operator-owned hCaptcha page.
6. A recorded provider contract version or retrieval date.

A stale software-development kit[fn:sdk] alone is insufficient.
