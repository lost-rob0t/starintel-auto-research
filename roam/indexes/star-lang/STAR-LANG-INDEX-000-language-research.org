* Selection Result

The comparative gate is closed. Common Lisp is selected as the implementation host. Racket remains the conformance, expansion, and tooling oracle. Guile Scheme remains the minimal portability witness.

This selection does not make Common Lisp the wire format. Validated normalized IR, canonical JSON manifests, generated bindings, and =star-message-v1= remain portable.

* Ordered Loops

** DONE Loop 000: Language Design Foundations

Define the bounded source, checked IR, effects, capabilities, durable execution, recovery, actor, reasoning, and testing model.

** DONE Loop 001: Common Lisp Baseline

Implement the shared fixture with ordinary macros, explicit registries, inspectable expansion, and no unrestricted =EVAL=.

** DONE Loop 002: Racket Embedded Baseline

Implement the same fixture with Racket forms, explicit registries, a normalized plan, tests, and a smoke benchmark.

** DONE Loop 003: Racket =#lang starintel= Baseline

Implement a dedicated module boundary and capture expanded output while reusing the embedded runtime.

** DONE Loop 004: Scheme Baseline

Implement the same fixture in Guile with =syntax-rules= and explicit runtime data structures.

** DONE Loop 005: Comparative Evaluation

Compare host integration, source boundaries, diagnostics, recovery, deployment, and maintained runtime evidence. Select Common Lisp as host.

** DONE Loop 006: Specification Libraries and Domain Servers

Define digest-locked imports, additive extension, relations, typed actors, domain servers, indexes, and resolver boundaries.

** DONE Loop 007: Normalized IR and cl-gserver Binding

Keep =send= in core IR and lower it to =tell= only in the optional adapter.

** DONE Loop 008: Core Surface and Wire Protocol

Compile closed =spec-library= syntax into qualified schema IR and portable contracts.

** DONE Loop 009: Canonical JSON and Generated Bindings

Emit byte-stable manifests and generated Python and TypeScript bindings.

** DONE Loop 010: Message Lifecycle and Delivery Semantics

Define correlation, causation, attempts, deadlines, idempotency, acknowledgements, retries, errors, and cancellation without claiming exactly-once execution.

** DONE Loop 011: Deterministic Dispatcher

Execute lifecycle rules as a pure state machine and standalone runtime baseline.

** DONE Loop 012: Transport Port and Settlement

Separate lifecycle outcomes from broker settlement and resume interrupted publication.

** DONE Loop 013: Optional cl-gserver Runtime Adapter

Preserve direct execution and add replaceable actor-system binding and runtime-directory capabilities.

** DONE Loops 014-017: Remoting and Recovery

Define BBP domain remoting, endpoint materialization, worker and dispatcher idempotency, and durable runtime journals.

* Preserved Invariants

1. source parsing is closed and does not execute host forms;
2. identifiers remain strings until validated at the production parser boundary;
3. document schemas, persistence, actor/tool/agent contracts, and named stages remain explicit;
4. relations retain source, predicate, and destination positions;
5. field access remains explicit and does not use dot syntax;
6. core IR remains runtime-neutral;
7. actor frameworks are optional adapters;
8. manifests and messages remain language-neutral;
9. lifecycle and transport settlement remain separate;
10. delivery is at least once and does not claim exactly once;
11. terminal duplicates replay without handler reinvocation;
12. runtime liveness affects routing rather than program validity;
13. research nodes never become StarIntel object types, predicates, or fields;
14. Auto-dig and Quasar consume contracts rather than define Star-Lang semantics.

* Promotion Result

The research gate is complete. =STAR-LANG-001= is the approved design and owns the active implementation slot. Future grammar, IR, manifest, lifecycle-identity, or public-API changes require a numbered design or a versioned additive revision.
