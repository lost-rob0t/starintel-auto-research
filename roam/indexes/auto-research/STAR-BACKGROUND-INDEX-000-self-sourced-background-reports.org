* Purpose

This index tracks the Auto Research work required before Auto Dig implements self-sourced background-report actors. The project builds source-backed investigative reports from primary public records, local mirrors, bounded official queries, entity resolution, and explicit coverage state.

It does not treat a commercial people-search report as the canonical evidence source.

* Explicit Non-Capabilities

The research currently rejects advertising the following as ordinary available source actors:

- arbitrary third-party FBI Identity History Summary lookup
- public nationwide DMV-person mirror
- NSOPW API or downloadable national NSOPW database
- interactive SAM.gov scraper when official APIs/extracts exist
- undocumented FINRA BrokerCheck bulk/API capability

These may change only after new source research verifies a supported contract.

* Implementation Order

2. Implement artifact hashing, source-release acceptance, current-projection rebuild, and reconciliation.
3. Implement the first bulk mirror set: Ohio voter, NPPES, FAA aircraft, FAA airmen, OFAC, LEIE, SAM exclusions, SEC submissions/company facts, IRS TEOS, IRS 990, FCC ULS/LMS.
4. Implement partitioned USAspending bulk acquisition.
5. Implement targeted federal court actors: CourtListener/RECAP then PACER fallback.
6. Implement Ohio business, Franklin County property/recorder/court, Ohio corrections, Ohio eLicense, and Ohio UCC source actors after exact source profiling.
7. Implement entity candidate generation, comparison, contradiction preservation, and resolution assertions.
8. Implement report coverage basis and evidence-backed report assembler.
9. Add additional states by source-platform family rather than hand-writing permanent actors for every jurisdiction.

* Completion Gates Before Auto Dig Claims Coverage

- every advertised source capability has a verified source profile
- every mirror retains immutable release and content-hash evidence
- full plus delta sources reconcile against later authoritative snapshots
- query-only sources expose truncation and freshness
- source-specific role semantics survive normalization
- identity merges are evidence-bearing assertions
- contradictions remain visible
- report sections expose their coverage basis
- unsupported and restricted-use sources remain explicit
- deterministic replay fixtures reproduce derived findings

* Footnotes and Glossary

- *Source family*: A group of upstream systems sharing data semantics or an acquisition protocol that can be served by one reusable adapter family.
- *Background report*: A versioned evidence projection over selected public-record source families for an identified investigative subject.
- *Coverage basis*: The exact set of source profiles, releases, queries, freshness states, and gaps used to produce a report.
