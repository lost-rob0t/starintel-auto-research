* Decision

Implement =NoneCapAdapterActor= as the reference adapter for the narrow hCaptcha token capability defined by [[id:star-captcha-000-broker-router][STAR-CAPTCHA-000]]. It is not a generic CAPTCHA adapter.

The actor accepts only broker-normalized messages. It has no public solve route, does not perform target authorization, and never advertises NoneCap's reserved future challenge names as active capabilities.

* Provider Mapping

| Broker operation | NoneCap operation |
|------------------+-------------------|
| =submitSolve= | =POST /v1/solves?wait=N= |
| =pollSolve= | =GET /v1/solves/{id}?wait=N= |
| =cancelSolve= | =DELETE /v1/solves/{id}= |
| =getBalanceOrQuota= | =GET /v1/me= |
| =reportOutcome= | =POST /v1/feedback= |
| =healthSnapshot= | account probe plus local circuit state |

The default base uniform resource locator[fn:url] is =https://api.nonecap.com=. It is configuration, never request input.

* Actor State

The actor owns provider credential reference, base URL, maximum concurrency, active attempts keyed by broker =attemptId=, provider solve identifiers, cancellation state, local counters, circuit-breaker state, and redacted latency/error measurements. It owns no durable result token.

* Error Mapping

| Provider response | Normalized failure |
|-------------------+--------------------|
| 400 invalid request | =invalidRequest= or =providerRejectedRequest= |
| 401 unauthorized | =providerAuthenticationFailed=; open circuit |
| 402 insufficient credits | =providerInsufficientBalance=; open circuit |
| 403 locked or forbidden | =providerDisabled=; open circuit |
| 404 unknown solve | =providerRejectedRequest= unless retention expiry is proven |
| 409 cancel conflict | retrieve and report actual terminal state |
| 422 validation error | =providerRejectedRequest=; not retryable |
| 429 limit | =providerConcurrencyLimited= |
| 500-series | =providerUnavailable=; bounded retry only when safe |

Unknown codes are preserved only as redacted =providerCode= values.

* Idempotency and Ambiguity

NoneCap does not document a create idempotency key.[fn:idempotency] Reserve the local journal before submission and record the solve identifier immediately. Duplicate broker deliveries attach to the same attempt. A failure before the provider identifier is known enters =ambiguousSubmission= and is never automatically recreated.

* Cancellation and Shutdown

On cancellation, call =DELETE /v1/solves/{id}= for active jobs. A conflict means the job is terminal and must be retrieved once. Shutdown stops new work, cancels active jobs where policy permits, deletes unconsumed result leases, flushes redacted metadata, and reports unresolved jobs.
