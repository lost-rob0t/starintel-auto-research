* Research Seed

Map each OSINT semantic against current StarLang/runtime and classify exactly one: already supported, expressible now as a library/pattern, StarLang extension needed, Common Lisp adapter needed, or external process required.

Current known primitives include domain-server compilation, typed domain tools, process-tool timeouts, deterministic dispatch, command deadlines, cancellation, retry outcomes/retry-after, terminal versus retryable failures, idempotency/replay, and runtime journal append/replay/order validation.

Open verification areas include bounded dynamic fan-out, recursive pivots/visited sets, playbooks/result bindings/branches, capability activation, provider health/circuit breaking, registry refresh/version pinning, typed partial aggregation, provenance-preserving dedup/corroboration, explainable correlation, causal cross-domain calls, scan budgets, proxy/Tor/I2P policy, opaque authenticated session refs, scheduled/stream triggers, and change sets.
