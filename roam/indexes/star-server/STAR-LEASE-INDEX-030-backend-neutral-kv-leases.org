* Purpose

This project index[fn:project-index] connects the research and design required to implement the StarIntel[fn:starintel] backend-neutral key-value lease store[fn:lease-store] tracked by =starintel-server= issue 30.

* Normative Design

- [[id:bc8066ec-d7a3-4d6a-afff-353d444e725a][STAR-SERVER-030 Backend-Neutral KV Lease Store Protocol]]

The design defines the Common Lisp[fn:common-lisp] protocol, canonical key codec, versioned persisted records, request-replay receipts, structured result algebra, runtime lifecycle, metrics, audit hooks, deterministic memory backend, etcd reference mapping, and shared backend contract suite.

* Research Basis

- [[id:1930fee2-2dc1-43b2-9dc2-9fd17ebc6289][STAR-RESEARCH-030 Backend-Neutral KV Lease Store]]

The research compares the guarantees needed from etcd, Consul, Redis, and DynamoDB; separates known deadline failure from an unknown mutation outcome; and concludes that backend neutrality must be capability-gated rather than reduced to the weakest available lock primitive.

* Implementation Order

1. Protocol objects, result kinds, deadline model, and canonical key codec.
2. Versioned lease, fence, and request-receipt serializers.
3. Runtime-owned lifecycle, bounded retry policy, metrics, and audit sinks.
4. Deterministic in-memory backend and full contract suite.
5. etcd v3 adapter and disposable-cluster conformance run.
6. Failure injection for leader loss, delayed responses, connection resets, expiration interruption, restart, and snapshot restore.
7. Target lease application service implementing issue-29 state transitions.
8. Runtime, actor, and HTTP integration without backend package imports.

* Review Gate

The design is ready for implementation review when:

- every issue-30 acceptance requirement maps to a normative section;
- every non-obvious term is defined locally;
- the Pages build resolves every Org-roam identifier;
- the generated site link checker passes;
- implementation does not begin before issue-29 state-transition decisions are treated as authoritative.
