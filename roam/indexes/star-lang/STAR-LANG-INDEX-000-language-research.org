* Final Selection

Common Lisp is the sole approved Star-Lang implementation language.

The parser, compiler, semantic engine, normalized IR producer, dispatcher, recovery system, document runtime, and execution runtime are owned by Common Lisp.

Every alternate implementation language is DENIED.

Versioned JSON remains available at system boundaries. JSON does not constitute another Star-Lang implementation.

The architecture decision is approved. Implementation completion remains tracked by the active implementation node and GitHub issue [[https://github.com/lost-rob0t/starintel-auto-research/issues/47][#47]].

=STAR-LANG-002= does not reopen the language decision. It specifies the durable actor runtime required by the approved Common Lisp implementation.

* Current Library Finding

The Common Lisp ecosystem already supplies useful portable threads, actors, parallel tasks, HTTP, URI, TLS, HTML, XML, JSON, CSV, compression, hashing, persistence, and testing libraries.

The missing layer is durable actor correctness: bounded mailboxes, supervision, generations, journals, replay, lease fencing, capabilities, artifact custody, revisioned authorities, and StarLang compiler support.

The project should wrap and contribute upstream first, and fork only after a conformance suite proves that public extension points are insufficient.

* Preserved Invariants

1. all Star-Lang implementation code is Common Lisp;
2. source parsing is closed and does not execute host forms;
3. identifiers remain strings until validated;
4. document schemas, persistence, actor, tool, agent, and dataflow contracts remain explicit;
5. relations retain source, predicate, and destination positions;
6. field access remains explicit and dot syntax is denied;
7. normalized IR contains no cl-gserver object types;
8. lifecycle and transport settlement remain separate;
9. delivery is at least once and does not claim exactly once;
10. terminal duplicates replay without handler reinvocation;
11. runtime liveness affects routing rather than program validity;
12. research nodes never become StarIntel object types, predicates, or fields;
13. Auto-dig and Quasar consume contracts rather than define Star-Lang semantics;
14. alternate implementation languages remain DENIED;
15. application actor systems may be authored entirely in StarLang while low-level runtime ports remain Common Lisp libraries;
16. mature ecosystem libraries are not rewritten without a measured semantic blocker.

* Archive Rule

This file records research history. It does not approve implementation completion and must not be used as the active implementation ledger.

Do not reopen language comparison or add another implementation language without a new explicit reversal from nsaspy.
