* Active Slice

This implementation is limited to the approved public-site redesign:

1. make the Auto-Dig root route a corpus dashboard;
2. generate compact dashboard projections rather than computing metrics from the complete corpus in the browser;
3. add documents-added-by-day, document-type, and relation-type visualizations;
4. add reviewed top-connected people and deterministic evidence-backed top findings;
5. add a dedicated all-datasets browser with casual card and analyst table views;
6. add Auto-Dig =Research= navigation to Auto-Research;
7. add reciprocal Auto-Research =Auto-Dig= navigation;
8. align shared shell typography, colors, focus treatment, and responsive behavior while preserving Auto-Research reading mode.
