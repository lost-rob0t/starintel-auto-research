* Scope

This index tracks the shared symbolic knowledge system across its proper repository boundaries. The ARADR control plane is =lost-rob0t/starintel-auto-research=. The product implementation repository is =lost-rob0t/star-kb=. The executable inference runtime is =lost-rob0t/prolog-query-server= plus CouchDB.

* Existing Design Decision Under Review

STAR-KB-001 V0.1 proposes:

- restricted readable Prolog as knowledge source;
- SWI-Prolog term parsing without consulting/executing source;
- JSON manifests for modules, bundles, source records, and generated releases;
- build-time dependency closure with one bundle -> one PQS KB release;
- alpha-normalized stable logical clause IDs;
- content-derived immutable release IDs;
- deterministic compilation to current PQS safe JSON AST;
- replay-safe staging and exact staged-set verification;
- PQS static analysis and pinned query/explain fixtures before activation;
- separate explicit activation with =strict:true= and caller-supplied CouchDB manifest =_rev=;
- rollback by reactivating a previously checked immutable release;
- synthetic =star.core.test= as the only V0.1 knowledge bundle;
- no production dialect corpus or StarIntel actor work in this first implementation slice.

This pre-existing design was not changed or approved by the dialect research pass.

* Footnotes and Glossary

- *ARADR control plane* :: The research/design/implementation-state documents recording what was researched, what is awaiting approval, and what implementation is active. Here it lives in =starintel-auto-research=.
- *PQS* :: =prolog-query-server=.
- *KB* :: Knowledge base, a named collection of facts and rules.
- *Bundle* :: Consumer-facing package of source modules plus transitive dependencies; the existing V0.1 design proposes publishing one bundle as one PQS release.
- *Release* :: Immutable version of one runtime KB.
- *Canonical knowledge* :: Reviewed reusable facts/rules, distinct from one investigation's observations.
- *Dialect enrichment* :: Analysis that attaches evidence-backed regional-language features or candidates to an input while preserving uncertainty; it is not synonymous with exact geolocation.
- *Implementation slot* :: The one active approved design copy under =roam/implement/<project>/= used to track actual implementation work.
