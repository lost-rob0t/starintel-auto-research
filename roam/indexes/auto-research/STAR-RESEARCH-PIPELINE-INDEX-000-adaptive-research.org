* REVIEW Parent Protocol Alignment Blocker

The revised Ohio contract exposed a mismatch in =STAR-RESEARCH-PIPELINE-003=. The parent design currently models logical source-profile IDs and a generic Coverage Ledger, but the Ohio completion contract requires:

- exact source-profile, deployment, search-plan, decision, gap, and assessment revision IDs
- a Route Assessment Authority or equivalent serialized state owner
- an independent review authority
- applicability-contract and policy-snapshot bindings
- revision-aware events, results, checkpoints, routing, and scheduler keys
- lease generations and fencing tokens for network attempts

The parent actor design must be amended and reviewed before any Ohio implementation begins. This is a protocol dependency, not an Ohio-only extension.
