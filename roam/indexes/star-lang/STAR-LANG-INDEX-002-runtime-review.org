* Current Evidence Summary

The canonical implementation repository exists. Its README says =prototype/= remains the authoritative working implementation during final package extraction. The prototype CLI currently lacks a runtime-compiler option. The Lisp API is extensible through =&rest= and keyword arguments but has no explicit runtime-compiler policy. The constructor runtime already uses Common Lisp =EVAL= when installing generated constructors, so the implementation gap is explicit strategy selection and conformance rather than introducing EVAL for the first time.

- *Conformance fixture* — Test-only controlled material used to verify runtime behavior.
