* Scope

This index covers the StarIntel-owned OAuth authorization-code provider required for Samsung Bixby account linking. It deliberately excludes capsule models/views/training, gateway business translation, and infrastructure deployment implementation, which remain in their owning repositories.

The user architecture is shared:

- guest Intelligence -> synthetic public reader;
- signed-in Intelligence -> StarIntel human principal with read/search authority;
- Operations -> same StarIntel human principal with explicitly stronger scopes.
