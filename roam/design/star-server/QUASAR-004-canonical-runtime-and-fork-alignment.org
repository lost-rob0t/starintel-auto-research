* Decision

=lost-rob0t/quasar= is the canonical Quasar[fn:quasar] repository and runtime for migrated durable operations.

It owns:

- the authoritative command channel for migrated graph and document mutations;
- persistent actor supervision;
- privileged local execution and runtime integrations;
- canonical revision and reconnect authority for migrated workspaces;
- durable operation replay and recovery boundaries assigned to the canonical runtime.

This document intentionally no longer owns the browser standalone design, Auto-Dig fork lifecycle, renderer-scale architecture, or exact protocol schemas. Those decisions are separate linked nodes so each can be reviewed and approved independently.

* Why This File Was Split

The original =QUASAR-004= combined several independently reviewable architecture choices:

1. canonical runtime authority;
2. browser standalone/web-edition authority;
3. Auto-Dig fork lifecycle and bridge typing;
4. graph renderer and scale tiers;
5. protocol layer ownership;
6. migration ordering and validation gates.

That made one approval appear to approve unrelated decisions. The file path and Org-roam[fn:org-roam] ID are preserved so existing links remain valid, but this node now owns only canonical runtime authority. The other concerns moved to focused nodes.

* Runtime Authority

For a workspace or subject migrated behind canonical Quasar runtime commands:

| Concern | Authority |
|---------+-----------|
| Durable graph/document mutation | =quasar= command channel |
| Canonical revision | =quasar= runtime |
| Persistent actor supervision | =quasar= runtime |
| Privileged local tools/integrations | =quasar= runtime |
| Reconnect and replay authority | =quasar= runtime |
| Browser transient interaction | Browser client, subject to QUASAR-005 |
| Renderer projection | Renderer adapter, subject to QUASAR-007 |
| Auto-Dig host specialization | Auto-Dig bridge, subject to QUASAR-006 |
| Exact graph command schema | QUASAR-003 |

The browser may keep caches, viewport state, selection state, or standalone data according to QUASAR-005. Those do not overrule newer canonical state for a migrated connected workspace.

* Required Invariants

1. One migrated mutable subject has one durable writer at a time.
2. Durable client mutations are requests to the canonical command boundary, not hidden local commits.
3. Revision conflicts are rejected or reconciled explicitly; stale clients do not silently overwrite canonical state.
4. Persistent actors that mutate migrated state do so through the same validated command semantics as human clients.
5. Renderer state is never the canonical database.
6. Canonical runtime loss/restart must not make browser cache state silently authoritative.
7. Research evaluation and promotion semantics remain owned by ADARD[fn:adard], not by Quasar runtime authority.

See [[file:QUASAR-005-web-edition-standalone-scope.org][QUASAR-005]]. It decides what =quasar-ui= may own in standalone mode and how it behaves when attached to canonical runtime services.

** Auto-Dig specialization

See [[file:QUASAR-006-auto-dig-fork-and-bridge-boundary.org][QUASAR-006]]. It decides the fork lifecycle, typed host bridge, upstream synchronization, and adapter-migration trigger.

** Renderer scale

See [[file:QUASAR-007-renderer-projection-and-scale-boundary.org][QUASAR-007]]. It decides projection tiers, safe-load guards, tiling, and benchmark requirements.

** Protocol schemas

See [[file:QUASAR-003-graph-document-command-protocol.org][QUASAR-003]]. It owns =star.graph.v1= and =quasar.control.v1= command/document contracts and conformance fixtures.

* Acceptance Gates

| Gate | Required proof |
|------|----------------|
| Single writer | Two connected clients cannot commit conflicting durable revisions without explicit rejection/reconciliation. |
| Command authority | Browser and actor durable mutations converge through the canonical command boundary. |
| Restart/replay | Runtime restart reconstructs canonical workspace state without promoting stale browser cache. |
| Revision handling | Stale revision fixture receives a structured conflict instead of silent overwrite. |
| Actor parity | A deterministic actor-produced mutation is validated by the same canonical command semantics as an equivalent user action. |
| Boundary documentation | =quasar=, =quasar-ui=, and Auto-Dig documentation point to the same authority split. |

* Non-Goals

- Do not define browser standalone features here; QUASAR-005 owns them.
- Do not define Auto-Dig fork synchronization or bridge payloads here; QUASAR-006 owns them.
- Do not choose graph renderers, WebGL[fn:webgl], WebGPU[fn:webgpu], or tiling strategies here; QUASAR-007 owns them.
- Do not duplicate graph command schemas here; QUASAR-003 owns them.
- Do not imply approval of QUASAR-005, QUASAR-006, or QUASAR-007 by approving this node.
