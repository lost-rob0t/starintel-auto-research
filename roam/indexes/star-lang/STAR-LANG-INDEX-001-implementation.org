* Scope

This index tracks the canonical StarLang implementation program.

Common Lisp is the sole approved Star-Lang implementation language.

Common Lisp remains the sole implementation language for StarLang source parsing,
semantic compilation, normalized IR ownership, deterministic runtime behavior,
conditions/restarts, and runtime composition. LISA, SWI-Prolog, and N-Prolog are
inference backends called through Common Lisp adapters; they are not alternate
StarLang implementations.

* Shared STAR URI Decision

StarLang consumes the shared RFC 3986 STAR URI model. New canonical resource
identity has the hierarchical form:

#+begin_example
star://<authority>/<resource-kind>/<resource-path>
#+end_example

New StarLang manifests MUST NOT emit the legacy tuple form
=star://domain:address:actor-name=. Legacy tuple input exists only through an
explicit compatibility/migration boundary and cannot become canonical ownership
inside =star-actor-protocol= or =prototype/=.

* Logic Runtime Decision

The approved backend IDs are:

#+begin_example
lisa
swi-prolog
n-prolog
#+end_example

=:auto= is deterministic materialization policy, not a backend.

- LISA owns production-rule/RETE working-memory profiles.
- SWI-Prolog owns the full relational/tabled and approved constraint profiles.
- N-Prolog owns a conservative independently fixture-proven portable relational subset.

All three use =star.logic.api/1= portable operations:

#+begin_example
assert!
retract!
solve
solutions
exists?
explain
#+end_example

No backend may expose raw untrusted Lisp/Prolog execution through StarLang.

* Prototype Retirement Program

Prototype retirement is mandatory and intentionally repeated across the approved
design set so later implementation work cannot quietly turn it into a permanent
compatibility swamp.

Implementation rules:

1. no new product feature is implemented only under =prototype/=;
2. each behavior has one final-system owner;
3. temporary prototype wrappers may only forward to the final owner;
4. wrappers contain no independent parser, policy, state machine, serializer,
   resolver, runtime, URI, logic, proof, or backend behavior;
5. each completed port slice deletes its superseded prototype implementation and
   migrates the corresponding tests/fixtures;
6. final ASDF systems load/test from a clean process without =starlang-prototype=;
7. Nix/Roswell/CLI/CI paths compose final systems directly;
8. docs/examples stop teaching prototype APIs after final equivalents exist;
9. a repository-wide audit checks source, tests, fixtures, scripts, ASDF, Nix,
   CI, CLI, examples, and docs for prototype dependencies;
10. once the overall port is proven complete, =prototype/= is deleted rather
    than retained as a fallback.

Implementation audit/removal epic:

- [[https://github.com/lost-rob0t/star-lang/issues/52][lost-rob0t/star-lang issue #52 — prove final-system port complete, then delete prototype/]]

If the audit is not green, issue #52 must enumerate the exact missing final owner
and finish that port before rerunning the deletion gate.

* Completion Gate

StarLang implementation is complete only when:

- final systems own all approved product behavior;
- direct and backend-specific conformance fixtures are green;
- durable replay/cancellation/failure semantics are proven;
- no final system imports or loads prototype packages/files;
- product CLI and public Lisp API work without prototype loading;
- shared STAR URI semantics have no competing prototype canonicalizer;
- logic/expert backends are final-owned;
- Nix and fresh-process ASDF checks prove final-system closure;
- issue #52 proves no required product dependency on =prototype/=;
- =prototype/= is removed after that proof.

A state where the final port is complete but the prototype remains as a fallback
is explicitly not accepted.

* Footnotes and Glossary

- *Final system* — Product ASDF system that directly owns implemented behavior and can load/test without the legacy prototype aggregate.
- *Inference backend* — LISA, SWI-Prolog, or N-Prolog engine used through the portable Common Lisp StarLang logic adapter contract; not an alternate StarLang implementation.
- *One-authority rule* — Exactly one implementation owner for migrated behavior; compatibility wrappers may forward but may not duplicate logic.
- *Prototype retirement* — Continuous deletion of superseded prototype ownership followed by complete removal of =prototype/= when repository-wide final-system conformance is proven.
- *Shared STAR URI model* — RFC-based canonical authority/resource identity owned by the shared STAR URI protocol rather than a StarLang-specific tuple grammar.
