* Implementation Ownership

Common Lisp owns parsing, validation, normalized IR, canonical manifest generation, standalone execution, conditions, restarts, and runtime adapters. Portable consumers receive manifests, generated bindings, versioned envelopes, and explicit contracts.

The implementation must preserve:

- a closed =.star= parser;
- source identifiers as strings until validation;
- runtime-neutral core IR;
- standalone execution without cl-gserver;
- optional actor-framework adapters;
- explicit persistence and at-least-once lifecycle semantics;
- language-neutral manifests and messages;
- no research-node or application-specific schema leakage.

* Completed Before This Pass

* Non-Negotiable Boundaries

1. Untrusted Star-Lang source never enters the Common Lisp reader.
2. No unrestricted =EVAL= enters compilation or execution.
3. Core IR never contains cl-gserver types.
4. Actor existence/readiness never defines program validity.
5. Research nodes never become StarIntel object types, predicates, or fields.
6. Auto-dig and Quasar consume contracts rather than define semantics.
7. Field access remains explicit; no dot syntax.
8. Cross-language consumers do not parse =.star= source independently.
