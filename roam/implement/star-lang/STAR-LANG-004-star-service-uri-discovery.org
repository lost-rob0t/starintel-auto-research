* Runtime boundary

The implementation intentionally does not introduce a global mutable registry.
The existing injected runtime-directory port remains the runtime discovery
boundary. This preserves standalone StarLang execution and allows a future
cl-gserver/Sento adapter, starintel-server registry, or other backend to supply
the observations.

* Next slice

After this implementation is green, starintel-server research/implementation
can consume the same service URI and runtime-directory semantics for gateway
routing. Quasar and BBP should register concrete runtime entries rather than
adding application-specific URI parsers.
