* Current Work Order

1. keep the Common Lisp and cross-language workflows green;
2. make source spans and origin chains first-class compiler data;
3. package the Common Lisp implementation as explicit ASDF systems;
4. replace shell-backed digest and retrieval calls with injected ports;
5. add one top-level conformance runner;
6. extract the implementation after package boundaries stabilize.

* Invariants

- Common Lisp is the host, not the wire format.
- Untrusted =.star= source never enters the Common Lisp reader.
- Normalized IR remains runtime-neutral.
- Manifests and messages remain language-neutral.
- Direct execution works without cl-gserver.
- Actor systems remain replaceable adapters.
- Research nodes never extend the StarIntel schema.
- Auto-dig and Quasar consume contracts rather than defining them.
