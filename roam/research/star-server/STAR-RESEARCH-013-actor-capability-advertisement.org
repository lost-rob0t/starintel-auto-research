* Finding

*KEEP.* FIPA Agent Management defines a Directory Facilitator that acts as a yellow-pages service: agents register service descriptions and other agents search those descriptions. That is strong prior art for StarIntel actor manifests carrying machine-readable capability information used by routing and orchestration.

The StarIntel-specific problem is contract precision. A useful capability description should identify input and output document types, operation names, preconditions, required credentials or network access, cost or budget class, concurrency limits, failure modes, and version compatibility rather than publishing a vague human label.

* Research Gaps

- Define the minimum actor capability schema.
- Decide static manifest versus runtime health and capability probes.
- Define capability versioning, deprecation, and incompatible changes.

* Footnotes and Glossary

- *Capability advertisement*: A machine-readable declaration of operations an actor can perform and the contracts required to invoke them.
- *Directory Facilitator*: FIPA agent service used for registering and discovering agent-provided services.
