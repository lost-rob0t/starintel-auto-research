* Scope

This index covers the operator-facing Discord application currently represented by =lost-rob0t/starintel-discord-tool=. The tool is treated as a controlled edge interface into StarIntel rather than as a second database, authorization system, research engine, or message broker.

* Canonical Research

- [[id:star-discord-research-001-operations-interface][STAR-DISCORD-RESEARCH-001 Discord Operations Interface Feature Research]] — review; evaluates database search, document submission, private direct messages, trusted target creation, Auto-Dig jobs, document notifications, and RabbitMQ-to-Discord channel bindings.

* Canonical Design

- [[id:star-discord-001-operations-interface-architecture][STAR-DISCORD-001 Discord Operations Interface Architecture]] — review; defines the Discord edge process, =discord-ops-bridge= gserver, capability authorization, supervised Auto-Dig adapter, document-ingest pipeline, subscriptions, and RabbitMQ projection actors.

* Implementation Order

1. Approve or revise the research conclusions.
2. Approve or revise the architecture and capability model.
3. Add the authoritative =discord-ops-bridge= runtime boundary to =starintel-server=.
4. Add a narrow client protocol to =starintel-discord-tool=.
5. Implement read-only search and identity/capability introspection first.
6. Add document submission with quarantine, validation, provenance, and idempotency.
7. Add subscription notifications.
8. Add trusted target creation and Auto-Dig job submission.
9. Add operator-approved RabbitMQ channel projections last.

The order intentionally keeps mutations and arbitrary event projection behind the read-only path until authorization, audit, replay, and failure behavior are observable.

* Footnotes and Glossary

[fn:gserver] A supervised actor-style service boundary that owns state and typed message handling inside the StarIntel runtime.

[fn:auto-dig] =lost-rob0t/starintel-gpt-auto-dig=, the Git-backed StarIntel research repository and recursive target-selection workflow.

[fn:projection] A bounded transformation of internal events into Discord notifications; it is not a second authoritative event store.
