* Research Question

If two or more sources say the same thing, should StarIntel keep one copy of the fact but still remember every source that reported it?

* Finding

*YES — KEEP ONE FACT, RETAIN EVERY SOURCE REPORT.* When multiple sources report the same or equivalent fact, StarIntel should avoid storing redundant copies of the normalized fact while preserving each source occurrence as evidence and provenance.

Knowledge-fusion research treats repeated observations from multiple sources and extractors as evidence to be combined while accounting for source reliability and extraction error. This supports separating physical deduplication from semantic evidence counting.

The critical caveat is dependence. Ten pages that copied one press release are not ten independent confirmations. StarIntel should preserve lineage sufficient to distinguish independent observations from syndicated, mirrored, quoted, scraped, or recursively copied material.

* Research Gaps

- Define source-independence and shared-lineage heuristics.
- Decide how near-duplicate text maps to claim-level corroboration.
- Separate confidence gained from independent sources from confidence gained from repeated extraction of one source.
- Reconcile the model with current StarIntel v0.9 provenance and evidence semantics.
- Define how StarLang actors add corroborating source occurrences without duplicating the canonical fact.
- Define how Quasar shows one fact with multiple source reports, including dependent/copied-source warnings.

* Footnotes and Glossary

- *Corroboration*: Multiple observations supporting the same claim.
- *Source dependence*: Evidence items sharing an upstream origin and therefore not representing independent confirmation.
