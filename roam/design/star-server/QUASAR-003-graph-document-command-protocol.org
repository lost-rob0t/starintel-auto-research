* Decision

This node is no longer implementation authority.

The operator corrected the boundary on 2026-08-29: the functionality previously discussed here belongs to the Star ingest server protocol rather than to Quasar.

Canonical replacement:

- [[file:../star-ingest/STAR-INGEST-001-star-ingest-server-protocol.org][STAR-INGEST-001 Star Ingest Server Protocol]]

Quasar remains a client/consumer of the ingest contract. Quasar-specific graph editing, renderer state, and runtime-control behavior must be designed separately and MUST NOT be smuggled back into the ingest protocol.

* Historical Note

The old document attempted to combine graph snapshots, mutation commands, runtime control, reconnect/replay, and conformance behavior under Quasar ownership. That combined boundary is intentionally retired rather than promoted.

* Implementation Rule

RAGE/implementers MUST NOT select this superseded node. Select =STAR-INGEST-001= when implementing server ingest functionality.
